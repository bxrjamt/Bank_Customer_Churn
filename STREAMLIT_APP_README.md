# 🏦 Sistema de Retención de Clientes - Banco Hispanis

Aplicación de Streamlit para visualizar y simular un sistema de retención de clientes bancarios basado en Machine Learning e IA generativa.

## 📋 Descripción

Esta aplicación permite a los equipos de negocio:
- **Identificar** clientes con alto riesgo de abandono (churn)
- **Analizar** perfiles de clientes en detalle
- **Generar** comunicaciones personalizadas de retención
- **Visualizar** el impacto potencial de las acciones de retención

## 🚀 Instalación

### 1. Instalar dependencias

```bash
pip install -r requirements.txt
```

### 2. Verificar componentes

```bash
python src/test_app.py
```

### 3. Ejecutar la aplicación

```bash
streamlit run src/app.py
```

La aplicación se abrirá automáticamente en tu navegador en `http://localhost:8501`
